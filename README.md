# Guia d’equacions de tercer d’ESO

Puja el contingut d’aquesta carpeta a l’arrel del repositori de GitHub.
A Settings > Pages, tria Deploy from a branch, main i / (root).

El web inclou 24 noms abreujats i només els PDF dels enunciats. No cal cap instal·lació ni compilació. Seleccionant un nom s’obre la variant amb el mateix número de la llista.
